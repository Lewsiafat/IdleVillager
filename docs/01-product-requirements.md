# 01 — 產品需求（PRD）

## 產品與版本

- 名稱：**IdleVillager**
- 版本：**MVP v0.2 規格**
- 定位：獨立於 Herdr 品牌的 macOS AI Agent 動態狀態列工具；首版對接 Herdr。

## 產品目的

為同時運行多個 AI Agent Session 的 macOS 使用者，提供低干擾、即時的工作狀態概覽，並可快速回到等待處理的 Herdr Pane。

## 三個不可妥協的需求

1. **狀態列直接看到數量及狀態**：不需要點開即可知道「工作中、待處理、閒置」的數量。
2. **展開後看到 Session 所在位置**：清楚標明 Workspace、Tab、Pane 及 Agent 類型／名稱。
3. **點選能回到所選 Session**：不只是開啟 Herdr，而是定位到使用者點選的 Tab / Pane。

## 核心使用流程

- 常態：在 Menu Bar 看到簡短的狀態摘要，例如 `⚒ 3  ✋ 2  💤 1`。
- 注意：待核准數量由 0 變 1，無需手動檢查每個視窗。
- 點擊：展開 Popover，檢視待處理 Session 與其所在 Workspace / Tab / Pane。
- 定位：點選該項，Herdr 對應視窗到前景，正確聚焦該 Pane。

## 功能範圍

### P0：核心功能

- 與本機 Herdr 連線、讀取完整 Session 階層。
- 依明確狀態來源統計數量、刷新清單。
- 區分同類型但不同 ID 的 Agent。
- 可以從所選列回到正確的 Herdr Pane。
- 斷線、Unknown 與沒有 Agent 時正確呈現。

### P1：動態角色

- 自動辨識 Claude / Codex / Gemini；未知則 Generic。
- 可共用的角色動作：幹活、舉手、躺平、交工。
- 不干擾專注的輕動畫；尊重系統減少動態效果。

### P2：小幅度自訂

- 切換「數量模式」與「少量角色模式」。
- 可調整排序、低干擾提醒與動畫開關。

## 非目標（第一版不做）

Token 費用、Prompt 輸入、聊天訊息顯示、歷史時間線、遠端監控、雲端帳號、大型 Dashboard、通知音效。

## MVP 驗收標準

- [ ] 三種主要數量顯示正確，且狀態變更可在合理延遲內反映。
- [ ] 展開清單中可識別 Workspace / Tab / Pane / Agent。
- [ ] 多個相同 Agent 的 Pane 不會混淆。
- [ ] 能成功將至少兩個不同 Tab / Pane 的目標逐一聚焦並切換前景。
- [ ] 待核准優先展示，且不誤標為已閒置。
- [ ] Herdr 斷線時顯示斷線，而非錯誤地顯示零個 Agent。
- [ ] 訊號不完整時顯示 Unknown。
- [ ] 不擷取對話全文、私密資料或金鑰。

## 風險

「工作 / 閒置 / 等待核准」精確性依 Herdr 版本與其訊號提供範圍；Pane 定位能力也須於目標環境逐項驗證。
